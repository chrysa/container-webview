- **C1 — Default branch mismatch.** `CLAUDE.md` and `README.md` say default branch is `main`;
  `AGENTS.md` says default branch `develop` and "squash merge only". The managed standards block also
  frames "`main` is production, `develop` is the workspace". Current checked-out branch is
  `chore/claude-config-drift-hook`. Owner should reconcile the stated default branch.

- **C2 — Python version mismatch.** `api/pyproject.toml` pins `requires-python >=3.12` and `README.md`
  badges "Python 3.12+"; the managed standards block references "Python 3.14 containers" and the
  build artefacts under `api/app/__pycache__/` are `cpython-314`. The runtime image appears to be 3.14
  while the declared floor is 3.12. Owner should confirm the intended version and align docs/pin.

- **C3 — Frontend dev server label.** `docker-compose.yml` comments call the frontend a "React / CRA
  dev server", but the stack is Vite (command `npm run dev`, `vite.config.ts`, `code/package.json`).
  Comment is stale.

- **C4 — Duplicate frontend components.** `code/src/components/{alerts,metrics,projects}` and
  `code/src/features/{alerts,metrics,projects}` both contain `AlertsPanel`, `MetricsTable`,
  `ProjectCard`. Looks like an in-progress migration to feature folders; owner should confirm which
  is canonical and remove the duplicate (not touched here).
